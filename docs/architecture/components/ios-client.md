# Component: M27 iOS client

Status: Draft · Version 0.1 · As built at `origin/main` 2c4905d

## 1. Responsibility

The native SwiftUI client (iOS 26, Liquid Glass, Swift 6.2) in its own repository, `lucas/on-my-radar-ios`. It is a peer client of `/api/v1`: it signs in with the emailed code, holds a device session as a bearer token in the Keychain, registers for APNs through this server, and mirrors the contract by vendoring a generated snapshot.

**Depends on:** M24 (`/api/v1`), M1 (device sessions), M10 (push registration), M25 (the snapshot).

**Used by:** People on iPhones.

**Invariants (and what enforces each):**

- It authenticates with `Authorization: Bearer omr_s_…` from `/api/auth/verify-code` with a `client` of `ios`; the server never sets a cookie for it, and the session appears in `/api/auth/sessions` and can be revoked.
- Its copy of the contract is `contract/contract-snapshot.json`, generated by M25; the Swift suite `swift test --package-path Packages/OMRContract` is the drift test.
- It registers a push device through `POST /api/notifications/push` with a `platform` field; the server binds the device to the session.
- Universal links: this server serves `/.well-known/apple-app-site-association` for bundle `io.onmyradar.app` with the components `/radar/*`, `/topic/*` and `/notifications` (`app.ts`; `apple-association.test.ts`).
