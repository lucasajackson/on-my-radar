Things to do before you rely on it:
{{- if not .Values.mail.provider }}
  * Mail is not configured (mail.provider is empty), so no sign-in code can be emailed.
    Set mail.provider=smtp and secrets.smtpUrl (or existingSecret with SMTP_URL).
{{- end }}
{{- if .Values.ingress.enabled }}
  * Your ingress must set the {{ .Values.trustedIpHeader }} request header to the client's real
    address, overwriting any value the client sent. Sign-in limits are per network and read it.
{{- else }}
  * When you put an ingress or proxy in front, have it set the {{ .Values.trustedIpHeader }} request
    header to the client's real address, overwriting any value the client sent.
{{- end }}
{{- if .Values.postgres.enabled }}
  * postgres.enabled=true is a throwaway database: one pod and one volume, no backups.
{{- end }}
  * Keep publicUrl as it is. OAuth, MCP connections and webhooks are built from it.
